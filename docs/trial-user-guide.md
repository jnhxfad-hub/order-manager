# 试用快速说明

## 试用前

1. 打开设置页，确认数据库路径和应用版本。
2. 先执行一次“备份数据库”，保存到安全位置。
3. 如果要测试导入，可使用 `docs/trial-kit/` 里的样例 CSV。

技术人员交付前可额外执行命令行备份：

```bash
pnpm run backup:real-db
```

## 基本流程

1. 客户页导入客户。
2. 商品页导入商品。
3. 商品页选择商品，点击“分配客户”。
4. 订单页新建订单，选择客户后导入订单明细。
5. 填写经手人、铝锭价，点击“下单”。
6. 库存页选择订单，先批量入库。
7. 入库完成后创建出库单，填写对应重量并打开打印预览。
8. 出库后回到设置页，再做一次备份。

## 注意事项

- 试用数据不要混入正式数据；正式试用前先备份当前真实库。
- 已下单订单不能删除，出库后订单库存会锁定。
- 打印时先看预览，确认内容无误后再打印。
- 恢复备份会覆盖当前数据；恢复前系统会自动生成安全备份。
- 如果需要命令行回滚，先退出 App，再执行：

```bash
pnpm run restore:real-db -- --backup /path/to/backup.sqlite --yes
```
